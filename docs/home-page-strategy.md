# Стратегия главной страницы — tikvatlibenu.co.il

Документ дизайн- и бренд-стратегии (OTW) для имплементации главной страницы. Без кода: только структура, копирайтинг (he + en), компоненты ДС с реальными пропсами, модель контента в Payload.

Источники: `src/ds/guidelines/docs/guides/01-brand-foundations.md`, `07-content-and-imagery.md`, `06-page-recipes.md`, `03-typography.md`, `04-layout-and-spacing.md`, `src/ds/catalog.json`, `src/ds/components.d.ts`, `src/ds/previews/Hero.mjs`, существующая конфигурация Payload (`src/collections/Campaigns.ts`, `src/globals/*`).

**Ключевой факт из кода:** коллекция `campaigns` — мемориальная («דף הנצחה וטופס תרומה לזכרו של נופל אחד»), с полями `dateOfBirth` / `dateOfDeath`, `excerpt`, `featured` («מוצג בדף הבית») и `order`. Это диктует деликатную подачу секции кампаний (см. §3.6).

---

## 1. Цели страницы и две аудитории

Главная решает две разные задачи одним и тем же средством — ясностью, спокойствием и видимой человечностью (01-brand-foundations).

### 1.1 Донор / волонтёр — «могу ли я доверять?»

Состояние: пришёл по ссылке или из поиска, решает, доверять ли организации деньги или время. Ему нужны: кто вы → что конкретно делаете → какой масштаб → кто за этим стоит → что говорят семьи → куда нажать.

Путь по странице:

| Секция | Работа для донора |
|---|---|
| Hero | За 5 секунд: имя, миссия, первое доказательство (highlights), кнопка «תרמו תקווה» |
| הפעילות שלנו | Что конкретно делают деньги: 4 направления работы |
| ההשפעה שלנו (navy) | Масштаб в честных цифрах |
| Тизер «О нас» | Кто за этим стоит, человеческое лицо |
| סיפורי משפחות | Социальное доказательство — слова самих семей |
| Кампании | Конкретный адресный способ пожертвовать |
| CTA-баннер | Закрытие: осязаемая сумма (₪180) + кнопка |

### 1.2 Семья — «мне помогут? как связаться?»

Состояние: стресс, телефон, часто больница. Ей нужно немедленно: «это про нас?» (диагнозы названы прямо в hero-абзаце — самоидентификация) и «как связаться» — не через воронку пожертвований.

Путь по странице:

| Элемент | Работа для семьи |
|---|---|
| Hero-абзац | Прямо называет: дети с онкологией и дети с CP, вся страна, от диагноза до выздоровления |
| `FloatingContact` (WhatsApp + телефон) | **Главный CTA семьи.** Закреплён в углу на каждом экране — семья никогда не ищет контакт |
| Вторичная CTA hero «הכירו את העמותה» | Спокойный, не денежный путь вглубь |
| הפעילות שלנו | «Покрывают ли они наш случай» |
| סיפורי משפחות | «Люди как мы» — снижает барьер обращения |

Принципиально: страница не делится на «донорскую» и «семейную» половины. Один спокойный рассказ обслуживает обоих; различаются только точки выхода (розовая кнопка ↔ плавающий WhatsApp).

### 1.3 Порядок секций v1 (адаптация рецепта из 06-page-recipes)

Рецепт автора ДС — 9 секций. Изменения v1 и их обоснование:

- **Убраны** (фаза 2, нет реального контента — жёсткое ограничение): события (`EventCard`), видео (`VideoCard`), блог (`ArticleCard`).
- **Добавлена** секция «Активные кампании» (Payload `campaigns`) — позиция 6, см. обоснование в §3.6.
- Истории семей остаются с временными деликатными цитатами (только имена, без диагнозов).

Итоговый стек (ритм тонов по 04-layout: white → navy → sky → white → soft → white; двух одинаковых тинтов подряд нет, navy один раз до финального баннера):

1. `Hero variant="split"` — белый фон, decor
2. `Section` (white) — הפעילות שלנו, 4 × `ServiceCard`
3. `Section tone="navy"` — ההשפעה שלנו, `StatGroup`
4. `Section tone="sky"` — тизер «О нас»
5. `Section` (white) — סיפורי משפחות, 3 × `TestimonialCard variant="tinted"`
6. `Section tone="soft"` — активные кампании (спокойный нейтральный фон — намеренно не цветной тинт)
7. `Section spacing="compact"` — `CTABanner tone="navy"`

Плюс на каждой странице: `SiteHeader` (розовая «לתרומה»), `SiteFooter`, `FloatingContact`.

## 2. Hero — глубокий разбор

Компонент: `Hero variant="split"` (пропсы из `components.d.ts`: `eyebrow`, `title`, `description`, `primaryAction`, `secondaryAction`, `imageSrc`, `imageAlt`, `tone`, `decor`, `highlights`).

### 2.1 Eyebrow

- **Работа:** мгновенная идентификация «кто говорит» до чтения заголовка; снимает вопрос «куда я попал» у пришедших по ссылке.
- **Копирайт:**
  - he: `עמותת תקוות ליבנו`
  - en: `Tikvat Libenu Nonprofit`
- **Обоснование:** так у автора ДС в `Hero.mjs`. Слово «עמותה» — сам по себе trust-сигнал (зарегистрированная НКО). Отвергли добавление номера ע״ר в eyebrow — регистрационный номер уместен в футере и у форм пожертвования (07-content), а не в первой строке страницы.

### 2.2 Заголовок (title) + Highlight

- **Работа:** это H1 страницы и главное бренд-высказывание. Должен работать на обе аудитории: донору — «вот наша миссия одним вздохом», семье — «здесь понимают, что нам больно, и здесь есть будущее».

**Вариант A — рекомендуемый:**

- he: `עוטפים את הכאב. <Highlight>בונים עתיד.</Highlight>`
- en: `Wrapping the pain. <Highlight>Building a future.</Highlight>`

Это слоган бренда, уже выбранный автором ДС для hero-превью. Две короткие клаузы — «боль признана, будущее строится» — точная эмоциональная механика бренда: надежда, а не страх. `Highlight` (variant="marker", жёлтый маркер по умолчанию) на второй, надеждной половине — акцент падает на будущее, не на боль. Дополнительный плюс: H1 = слоган делает фразу ownable и запоминаемой; никакой другой заголовок на странице не подсвечивается (правило: один highlighted heading на экран).

**Вариант B — отвергнут:**

- he: `אף משפחה לא נשארת עם זה <Highlight>לבד</Highlight>`
- en: `No family faces this <Highlight>alone</Highlight>`

Сильно для семей, но открывает страницу отрицанием («не остаётся одна») и подсвечивает маркером негативное слово «לבד» — против правила «надежда, а не страх». Эту мысль переносим в тело тизера «О нас» (§3.4), где она работает как поддержка, а не как первый крик.

**Вариант C — отвергнут:**

- he: `<Highlight>יד ביד</Highlight> — מהאבחון ועד ההחלמה`
- en: `<Highlight>Hand in hand</Highlight> — from diagnosis to recovery`

Честно описывает модель сопровождения, но дженерик — так может сказать любая НКО; нет бренд-капитала. Формула «מרגע האבחון ועד ההחלמה» уже живёт в подзаголовке, дублировать её в H1 расточительно.

### 2.3 Подзаголовок-абзац (description)

- **Работа:** одна фраза, которая делает миссию конкретной и даёт семье самоидентификацию: названы обе группы детей, полный спектр помощи, география. Донору — «понятно, на что идут деньги».
- **Копирайт:**
  - he: `מלווים ילדים חולי סרטן וילדים עם שיתוק מוחין (CP) — ואת המשפחות שלהם — רפואית, רגשית, חברתית וכלכלית, מרגע האבחון ועד ההחלמה. בכל רחבי הארץ.`
  - en: `We accompany children with cancer and children with cerebral palsy (CP) — and their families — medically, emotionally, socially and financially, from diagnosis to recovery. All across Israel.`
- **Обоснование:** база — текст автора ДС из `Hero.mjs`, но он упоминал только онкологию; живой сайт (title: «תמיכה בילדים חולי סרטן ו־CP») и брендбук требуют обе группы — добавили CP. «בכל רחבי הארץ» — конкретика вместо абстракции и ответ на первый вопрос семьи из периферии. Короткие сегменты через тире вместо длинного предложения — правило коротких фраз. Отвергли перечисление услуг здесь — для этого секция 2.

### 2.4 Первичная CTA

- **Работа:** единственная розовая кнопка экрана (правило `Button variant="primary"` — одна на вью) — путь донора.
- **Копирайт:**
  - he: `תרמו תקווה` → `/donate`, `icon: "heart"`
  - en: `Donate Hope` → `/en/donate`
- **Обоснование:** формула автора ДС. Глагол во множественном числе («תרמו») по правилу голоса + объект «תקווה» превращает транзакцию в смысл — жертвуют не деньги, а надежду; перекликается с именем амуты. Отвергли голое «לתרומה» в hero (оно остаётся стандартом для кнопки в шапке и в баннере — там контекст уже задан); отвергли «עזרו לנו» — просительная интонация, бренд «спокойный и уверенный», не «urgent, guilt-driven».

### 2.5 Вторичная CTA

- **Работа:** спокойный маршрут для недозревшего донора и для семьи — узнать, кто мы, без денег.
- **Копирайт:**
  - he: `הכירו את העמותה` → `/about`
  - en: `Get to Know Us` → `/en/about`
- **Обоснование:** глагол-приглашение во мн. числе, тёплое «познакомьтесь» вместо канцелярского «אודות». Отвергли «צרו קשר» как вторичную CTA — контакт уже постоянно доступен через `FloatingContact`, дублировать его в hero значит потратить слот.

### 2.6 Highlights (список под кнопками)

- **Работа:** три мгновенных доказательства масштаба — «нам можно доверять» до скролла. Формат пропса: `highlights: { value, label }[]`, максимум три.
- **Копирайт (типы метрик — цифры запросить у клиента, см. §5):**
  - `{ value: "‹N›+", label: "משפחות מלוות" }` / en: `families accompanied`
  - `{ value: "‹N›", label: "מתנדבים פעילים" }` / en: `active volunteers`
  - `{ value: "‹N›", label: "שנות פעילות" }` / en: `years of activity`
- **Обоснование:** триада «кому помогли / кто помогает / как давно» закрывает три оси доверия: масштаб, живые люди, устойчивость. Числа из превью автора ДС (1,250+ / 320 / 12) — **демо-данные, публиковать нельзя**; правило цифр: только реальные, честное округление. Если клиент не даст цифру для одной из позиций — заменить на «ימי כיף בשנה» или опустить (можно две), но не выдумывать.

### 2.7 Фото в petal-маске

- **Работа:** «видимая человечность» — эмоциональный якорь первого экрана; доказательство реальности сильнее любого текста.
- **Контент:** реальный тёплый момент из деятельности амуты — волонтёр и ребёнок играют/творят/смеются; больница допустима, если момент тёплый. Кадр 4:5, лица в верхней-центральной трети (маска petal кадрирует края; `position="center top"` по 07-content). Письменное согласие родителей обязательно; если согласия нет — руки/спины/активность без лиц.
- **Alt:**
  - he: `מתנדבת ויֶלד צוחקים יחד בפעילות של העמותה`
  - en: `A volunteer and a child laughing together at an amuta activity`
- **Обоснование:** правило «достоинство прежде всего» — дети как дети, не как пациенты: никаких капельниц, «до/после», жалости. Отвергли сток: он ломает доверие обеих аудиторий; до получения реального фото `imageSrc` не передавать вовсе — `Picture` отрисует фирменный баттерфляй-плейсхолдер (это лучше стока — прямое указание 07-content).
- **Alt в модели контента:** локализуемое поле (см. §4), т.к. alt — тоже копирайт.

### 2.8 Бабочка-декор

- **Работа:** фирменная подпись; единственный момент «полноцветной бабочки» на странице.
- **Решение:** ничего не добавлять вручную — в `Hero variant="split"` полноцветная бабочка, сидящая на углу фото, **встроена** (01-brand-foundations). Правило: полноцветная бабочка — один раз на страницу; значит, `CTABanner` внизу использует только бледный watermark (`decor` баннера), а между ними бабочек нет.
- **Отвергли:** `ButterflyDecor` как watermark в hero — в split-варианте он не нужен (watermark — для `variant="centered"`), и два декоративных жеста в одной секции нарушают «одна декоративная идея на секцию».

### 2.9 Фон

- **Решение:** `tone` не передавать (белый по умолчанию) + `decor={true}` — большое мягкое «крыло»-поле за фото, срезанное краем секции.
- **Обоснование:** белый держит спокойствие и даёт контраст petal-фото и жёлтому маркеру highlight; крыло-поле — каноническая форма декора №1 («поле, срезанное краем»). Отвергли `tone="sky"`: тинт зарезервирован за тизером «О нас» (§3.4) — иначе нарушим ритм чередования тонов и утопим бледное крыло-поле.

## 3. Остальные секции

### 3.1 הפעילות שלנו — что мы делаем

- **Цель:** донору — «на что конкретно идут деньги»; семье — «покрывают ли они наш случай». Четыре опоры холистической модели.
- **Компоненты:** `Section` (white) → `SectionHeader` → `Grid columns={4} gap={6}` → 4 × `ServiceCard` (пропсы: `icon`, `title`, `description`, `tone`, `variant`). Тона по кругу: teal → pink → yellow → navy (рецепт). `variant="plain"` (белые карточки на белом — с мягкой тенью), `headingLevel={3}`. `href`/`linkLabel` не передавать в v1 — внутренних страниц услуг ещё нет (фаза 2).
- **SectionHeader:**
  - eyebrow — he: `מה אנחנו עושים` / en: `What we do`
  - title — he: `הפעילות שלנו` / en: `Our Work`
  - description — he: `ליווי הוליסטי — רפואי, רגשי, חברתי וכלכלי — לאורך כל הדרך.` / en: `Holistic support — medical, emotional, social and financial — all along the way.`
- **Карточки** (иконки — lucide-имена, сверить с реальным набором `Icon` при имплементации):

| # | tone | icon (предложение) | he | en |
|---|---|---|---|---|
| 1 | teal | `stethoscope` | **סיוע רפואי וכלכלי** — מממנים תרופות חיוניות וטיפולים שאינם בסל הבריאות, ומקלים על הנטל הכלכלי של המשפחה. | **Medical & financial aid** — We fund vital medications and treatments outside the public health basket, and ease the family's financial burden. |
| 2 | pink | `heart-handshake` | **ליווי רגשי קבוע** — אוזן קשבת ותמיכה רגשית להורים, לאחים ולילדים — באופן קבוע, לא רק ברגעי משבר. | **Ongoing emotional support** — A listening ear and steady emotional support for parents, siblings and children — consistently, not only in moments of crisis. |
| 3 | yellow | `users` | **מתנדבים לצד הילדים** — המתנדבים שלנו מגיעים אל הילדים בבתי החולים, בבית ובמסגרות החינוך — בכל רחבי הארץ. | **Volunteers at the children's side** — Our volunteers come to the children — in hospitals, at home and at school — all across Israel. |
| 4 | navy | `sun` | **ימי כיף ומחנות** — ימי כיף, מחנות ונופשים בארץ ובחו״ל — רגעים של ילדות, חברים וצחוק. | **Fun days & camps** — Fun days, camps and getaways in Israel and abroad — moments of childhood, friends and laughter. |

- **Источник данных:** global `home-page` (заголовок секции + 4 карточки; иконка — select). Обоснование редактируемости: клиент сможет уточнять формулировки услуг без релиза.
- **Запросить у клиента:** подтвердить 4 направления и формулировки (особенно «שאינם בסל הבריאות» — точна ли), названия программ, если есть устоявшиеся.

### 3.2 ההשפעה שלנו — цифры (navy)

- **Цель:** масштаб и устойчивость за один взгляд; тёмная полоса — визуальная пауза и «серьёзный» регистр для донора.
- **Компоненты:** `Section tone="navy"` → `SectionHeader` (`eyebrowTone="inverse"`, заголовок `tone` наследует инверсию секции) → `StatGroup variant="plain" columns={4}` → до 4 × `Stat tone="inverse"` (пропсы: `value` — уже отформатированная строка, `label`, `description?`, `icon?`).
- **SectionHeader:**
  - eyebrow — he: `במספרים` / en: `In numbers`
  - title — he: `ההשפעה שלנו` / en: `Our Impact`
  - description — he: `נתונים נכונים ל־‹שנה›.` / en: `Figures current as of ‹year›.` (правило: называть год)
- **Типы метрик (все значения — запросить у клиента; максимум 4 в ряд):**

| value (формат) | label he | label en |
|---|---|---|
| `‹N›+` | משפחות מלוות | Families accompanied |
| `‹N›` | מתנדבים פעילים | Active volunteers |
| `‹N›` | ימי כיף ואירועים בשנה | Fun days & events a year |
| `₪‹N›` (напр. `₪1.2M`) | מימון תרופות וטיפולים בשנה | Medications & treatments funded a year |

Если метрик меньше — `columns={3}`. Дублирование первых двух с hero-highlights допустимо (hero — беглое доказательство, здесь — развёрнутое с иконками), но лучше в hero оставить «שנות פעילות», а здесь — годовые метрики. Честное округление: «1,250+», не «1,253».

- **Источник данных:** global `home-page` (массив статов). Числа меняются раз в год — идеальный кейс для админки.
- **Запросить:** сами цифры + актуальный год + согласие на публикацию.

### 3.3 Тизер «О нас» (sky)

- **Цель:** человеческое лицо организации; мостик на `/about` для обеих аудиторий.
- **Компоненты:** `Section tone="sky" decor={true}` (петал-декор в углу — один жест) → `Grid columns={2} gap={12} align="center"`: колонка текста (`Eyebrow` + `Heading level={2}` + `Paragraph` + `TextLink variant="standalone" arrow tone="primary"`) + `Picture shape="petal" ratio="4/5" tone="sky"` (фото — команда/волонтёры; до фото — плейсхолдер).
- **Копирайт:**
  - eyebrow — he: `מי אנחנו` / en: `Who we are`
  - title — he: `נעים להכיר: תקוות ליבנו` / en: `Meet Tikvat Libenu`

### 3.5 Активные кампании (soft) — новая секция

- **Стратегическое решение.** Кампании — мемориальные страницы (это подтверждает сама коллекция: «דף הנצחה... לזכרו של נופל אחד», поля даты рождения/ухода). Напряжение: бренд говорит «надежда, а не страх», а секция говорит о памяти. Решение — **рамка «память, которая продолжает делать добро»**: не скорбь, а продолжение — каждое пожертвование в память о ребёнке сопровождает живые семьи. Это соединяет мемориал с «בונים עתיד».
- **Позиция — №6, после историй семей, перед финальным баннером.** Обоснование: (а) страница открывается жизнью и надеждой — мемориальный контент не должен задавать тон первого экрана; (б) к этому моменту посетитель уже видел, на что идут деньги — адресная кампания становится осмысленным выбором; (в) прямо перед закрывающим CTA — путь донора не обрывается. Отвергли позицию сразу после hero (донорская логика «главный продукт вперёд»): превратила бы первый экран в стену памяти и сломала бренд-обещание. Отвергли позицию после финального CTA — ниже баннера ничего не живёт.
- **Тон секции:** `Section tone="soft"` — тихий нейтральный фон; намеренно не цветной тинт (sky/sun/blush — «весёлые» тона) и не navy (слишком траурно в этом контексте). Декор не добавлять — сдержанность и есть жест.
- **Компоненты:** `SectionHeader` (+ `action`: `TextLink variant="standalone" arrow` «לכל הקמפיינים» → `/campaigns` — если в v1 есть индексная страница; иначе опустить) → `Grid columns={3} gap={6}` из карточек кампаний. Спецкомпонента CampaignCard в ДС нет — собрать из базовых: `Card variant="elevated"` → `Picture ratio="3/2" shape="soft"` (coverImage) → `Heading level={3} size="h4"` (title = имя) → `Paragraph size="xs" tone="muted"` — годы жизни как LTR-остров: `<span dir="ltr">2008–2021</span>` (только годы, без полных дат и без слов «נולד/נפטר» — сдержанность) → `Paragraph size="sm"` (excerpt) → `TextLink variant="standalone" arrow` «לסיפור ולתרומה». Вся карточка — одна ссылка на `/campaigns/[slug]` (по образцу ArticleCard). При одной опубликованной кампании грид с тремя колонками отрисует одну карточку слева — приемлемо; альтернатива (рекомендация имплементации): при `count === 1` рендерить широкую горизонтальную карточку (`Grid columns={2}` внутри `Card`: фото + текст).
- **SectionHeader:**
  - eyebrow — he: `קמפיינים פעילים` / en: `Active campaigns`
  - title — he: `זיכרון שממשיך לעשות טוב` / en: `A Memory That Keeps Doing Good`
  - description — he: `קמפיינים שהוקמו לזכרם של ילדים אהובים. כל תרומה ממשיכה את דרכם ועוטפת משפחות נוספות.` / en: `Campaigns created in memory of beloved children. Every donation carries their path forward and wraps more families in care.`
  - CTA карточки — he: `לסיפור ולתרומה` / en: `Read & Donate`
- **Источник данных:** коллекция `campaigns`: `status = published` **и** `featured = true` (чекбокс уже существует и подписан «מוצג בדף הבית»), сортировка по `order`, затем по новизне; лимит 3. Поля карточки: `title`, `slug`, `coverImage`, `excerpt` (fallback — усечённый plain-text из `description`), `dateOfBirth`/`dateOfDeath` (рендерить только если заполнены оба; только годы). Заголовок/описание секции — из global `home-page`.
- **Запросить:** одобрение семьи кампании на показ на главной (featured), подтверждение формулировки заголовка секции у клиента (чувствительная зона — обязательно согласовать), заполненный `excerpt` для опубликованной кампании.

### 3.6 Финальный CTA-баннер

- **Цель:** закрыть путь донора осязаемым предложением; последний экран перед футером.
- **Компоненты:** `Section spacing="compact"` (white) → `CTABanner tone="navy" layout="inline" decor={true} headingLevel={2}` (пропсы: `title`, `description`, `primaryAction`, `secondaryAction`). Watermark-бабочка баннера — бледная, правило «полноцветная — один раз» не нарушено.
- **Копирайт:**
  - title — he: `רוצים להיות חלק מהתקווה?` / en: `Want to Be Part of the Hope?`
  - description — he: `תרומה חודשית של ₪180 מעניקה לילד ולמשפחתו יום כיף שלם. וכל סכום — קטן או גדול — עוטף משפחה ברגע הכי קשה.` / en: `A monthly gift of ₪180 gives a child and their family a whole fun day. And any amount — big or small — wraps a family at their hardest moment.`
  - primaryAction — he: `{ label: "לתרומה", href: "/donate", icon: "heart" }` / en: `Donate`
  - secondaryAction — he: `{ label: "צרו קשר", href: "/contact" }` / en: `Contact Us`
- **Обоснование:** формула «₪180 — יום כיף» — эталон осязаемости из брендбука (₪180 = ח״י × 10, дефолт помесячного пожертвования из 07-content). Здесь кнопка — короткое «לתרומה»: контекст уже создан описанием, глагольная форма из брендбука. «עוטף» перекликается со слоганом. Вопрос-заголовок мягко вовлекает без давления вины. **Проверить у клиента:** действительно ли ₪180 покрывает день веселья — если нет, подобрать честный эквивалент (правило honesty).

## 4. Модель контента в Payload

### 4.1 Новый global `home-page` (label: Home Page / דף הבית, group: Content, `access.read: () => true`, hook `revalidateGlobalOnChange` — как у существующих globals)

Структура — `tabs` по секциям (паттерн `SiteSettings`). «localized: да» — переводимо per-locale (he/en).

**Tab «Hero» (`hero`, group):**

| Поле | Тип | localized | Примечание |
|---|---|---|---|
| `eyebrow` | text | да | |
| `title` | text | да | Полный текст H1 |
| `titleHighlight` | text | да | Точная подстрока `title`, оборачиваемая в `<Highlight>`; не найдена → рендер без акцента |
| `description` | textarea | да | |
| `primaryCta` | group { `label` text (да), `url` text (нет) } | — | |
| `secondaryCta` | group { `label` text (да), `url` text (нет) } | — | |
| `image` | upload → media | нет | Пусто → фирменный плейсхолдер `Picture` |
| `imageAlt` | text | да | Alt — тоже копирайт |
| `highlights` | array (max 3) { `value` text (нет), `label` text (да) } | — | Числа — LTR-строки, общие для локалей |

**Tab «Services» (`services`, group):** `eyebrow` / `title` / `description` — text/textarea, localized; `items` array (max 4) { `icon` select (курируемый список имён из набора `Icon`), `title` text (да), `description` textarea (да) }.

**Tab «Impact» (`impact`, group):** `eyebrow` / `title` / `description` (в description админ вписывает год) — localized; `items` array (max 4) { `value` text (нет — «1,250+», «₪1.2M»), `label` text (да), `icon` select (опц.) }.

**Tab «About teaser» (`about`, group):** `eyebrow`, `title`, `body` (textarea, да), `image` upload (нет), `imageAlt` (да), `ctaLabel` (да); `url` статичен в коде → `/about`.

**Tab «Stories» (`stories`, group):** `eyebrow`, `title` — localized; `items` array (max 3) { `quote` textarea (да), `name` text (да), `role` text (да) }. Описание поля в админке: «רק שם פרטי, בלי אבחנות» — правило приватности прямо в UI.

**Tab «Campaigns» (`campaignsSection`, group):** `eyebrow`, `title`, `description`, `cardCtaLabel` — все localized. Сами кампании сюда НЕ кладутся — читаются из коллекции.

**Tab «CTA banner» (`ctaBanner`, group):** `title` (да), `description` (да), `primaryCta` group { label (да), url (нет) }, `secondaryCta` group { label (да), url (нет) }.

### 4.2 Что читается из коллекций

| Секция | Источник | Выборка |
|---|---|---|
| Кампании (§3.5) | коллекция `campaigns` | `status=published AND featured=true`, sort: `order` asc, затем `-createdAt`, limit 3; поля: title, slug, coverImage, excerpt, dateOfBirth, dateOfDeath |
| Все изображения | коллекция `media` | через upload-поля |
| `FloatingContact`, футер | global `site-settings` | `contactPhone`, `social` (whatsapp) — см. чек-лист: возможно, добавить отдельное поле `whatsappNumber` в site-settings (для `FloatingContact` нужен формат «только цифры, международный») |
| Шапка/футер/кнопка «לתרומה» | global `navigation` | существующие `headerLinks`, `headerCta`, `footerLinks` |

### 4.3 Статика в коде

Порядок и тона секций, композиция компонентов, `variant`/`tone`/`columns`, декор (крыло hero, петал sky-секции, watermark баннера), ротация тонов ServiceCard/TestimonialCard, `/about` и `/campaigns/[slug]` в ссылках, fallback-копирайт из этого документа на случай пустого global (страница никогда не рендерится «дырявой»).

Смежные правки вне global: (1) `site-settings` — поле `whatsappNumber` (text, не localized) для `FloatingContact`; (2) `faqs` на главной не используются (v1); (3) навигация v1: אודות · קמפיינים · שאלות ותשובות · צרו קשר + кнопка לתרומה (5 ссылок — в пределах правила 5–6; блог/галерея из рецепта — фаза 2).

## 5. Чек-лист материалов от клиента
